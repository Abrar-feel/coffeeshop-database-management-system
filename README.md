# CoffeeShop Database Management System

A relational database project developed using **Microsoft Access** as part of our Database course.

## Project Overview

The system manages customer information, menu items, orders, order details, and payment records.

It includes **database tables, relationships, queries, forms, subforms, and reports** for efficient data management and retrieval.

## Tools & Technologies

- Microsoft Access
- SQL / Access Queries
- Relational Database Design
